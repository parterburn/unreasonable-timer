Updates install themselves.

- New: Settings ▸ Updates ▸ Install updates automatically, on by default. The app checks once a day; a new version downloads in the background and installs the next time you quit the app, so a running timer is never interrupted. Turn it off to be asked first, as before.
- Opening a saved timer with its own text sizes no longer flips the preview to "Time is up". The preview still jumps to the right moment while you change a size.
