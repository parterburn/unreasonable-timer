Share timers, and type a text size.

- Right-click a timer in the sidebar or on the countdown and choose Copy Link or Share…, or use the Share button at the bottom of the setup screen. The link opens the Eco web timer with the same time, text and theme, so anyone can run it in a browser. It also carries the Mac app's own settings (accent, sound, text sizes) and the saved timer's name.
- Open a shared link in the app and the countdown comes up paused, as on the web; "Save as Timer…" suggests the name it was shared under.
- Click a size percentage on the setup screen to type a new one, from 50 to 200. Sizes in that range apply as you type, so the preview follows; anything outside it is held to the range when you press Return or click away.
- While typing in a size, ↑ and ↓ step it by 10%, as the arrows beside it do. Both now land on round numbers, so a typed 55 steps to 60 or 50.
- Clicking into a size shows the moment its text appears in the preview, as clicking into the text does.
- The text size boxes are now read out by VoiceOver.
