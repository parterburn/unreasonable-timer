No text at zero, if you like, and shared links can open in the app.

- "At zero" can be left empty. Time's up then shows just the overtime count, or nothing at all when the timer stops at zero. (A shared link to such a timer shows "Time is up!" on the web timer, which always has text at zero.)

- Reset says what it resets to, "Reset to 10:00", in the timer's right-click menu, the Timer menu, the menu bar and the Dock.

- The app is now signed to answer for unreasonable.eco. Once unreasonable.eco lists it, a shared timer link (https://unreasonable.eco/timer?…) clicked in Safari, Mail, Messages and other apps that hand links to apps opens the countdown here instead of the web timer. Chrome and other browsers still open the web timer.
